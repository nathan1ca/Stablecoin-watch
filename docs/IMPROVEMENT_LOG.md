5. 빈 상태: 코너 흐름 ETH 0건일 때 차트·표·막대에 안내 문구.
6. 탭: 주소 해시로 탭 공유·새로고침 유지(#premium 등), 아래로 읽다 탭을 바꾸면 새 탭 첫머리로, 좁은 화면에서 가장자리 페이드로 스크롤 가능 표시.
