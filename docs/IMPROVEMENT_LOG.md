## 2026-10-07 (6) 국내 거래소 거래지원 표시 (auto/2026-10-07-6)

- 화면(네이선 요청으로 개편): 종목별 현황의 종목과 담보 사이에 ‘국내 거래소’ 열 — 거래지원 중인 거래소 아이콘을 고정 순서(업비트·빗썸·코인원·디지털엑스·고팍스)로 놓고, 아이콘 오른쪽 위에 작은 글자로 마켓(원=KRW·B=BTC·T=USDT) 표기. 투자유의는 주황 테두리, 수집 실패분은 흐리게. 열 머리글로 거래소 수 정렬, ‘국내 거래지원’ 거르기 칩, 발행사 개요에 거래소별 마켓. 별도 절은 거래소별 요약 카드(종목 수·원화마켓 수)·핵심 문장·최근 변동으로 축소, 최근 7일 거래지원 시작·종료는 주요 신호.
- 거래소 아이콘: 각 거래소 공식 아이콘(파비콘)을 수집기가 한 번 받아 `site/data/ex-icons/` 에 사본으로 둔다(방문자 브라우저는 거래소 서버에 접속하지 않음, SVG 제외). 수집 서버(미국)에서 홈페이지가 막히는 빗썸(시간 초과)·코인원(403)은 애플 앱스토어 공식 앱 아이콘(판매자명 일치 확인). 못 받으면 머리글자 배지(U·B·C·D·G).
- 오탐 방지: 거래소 수집 실패 회차는 종료로 보지 않고 직전 값을 `*`로 이어 표시. 첫 수집은 기준선으로만 저장(이벤트 없음). 동명 티커 제외 — U·M(한 글자), FRAX(2025년 거버넌스 토큰 FXS 가 FRAX 로 티커 변경, 국내 상장분은 거버넌스 토큰일 가능성).
